## The sync step, which is easy to forget

The repo-root `README.md`, `CHANGELOG.md`, `LICENSE` and `README_PIC*.png` are the source of
truth. The copies inside `buttonfu-extension/` are generated and hash-verified before packaging.
Edit the root files, then from the repo root run:

```powershell
npm run sync-package-files --prefix buttonfu-extension
```

Skipping it leaves the packaged extension describing the previous version, and the hash check
fails at package time rather than now.
